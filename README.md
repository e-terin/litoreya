# litoreya - Вэб приложение для хранения шифрованной информации

## Описание проекта
Приложение хранит на сервере зашифрованные посты разных типов (текст, пароль)  
Стек состоит из двух приложений: фронтовое на NextJs и бэкенд на Laravel  
Локально для разработки используется docker сборка  
БД по умолчанию MySQL  
Приложение изначально должно работать на shared хостинге(просто файлы php под управлением apache) 
а затем далее сделаем и на собственном VPS сервере (docker образы)  
При заходе на сайт пользователя встречает окно логина/регистрации  
После ввода пароля и ключевой фразы пользователь попадает на свой дашборд, где содержится категоризированный список постов.  
Пароль - нужен для процесса аутентификации пользователя на сервере, а ключевая фраза для шифрования/дешифрования информации уже на стороне клиента, в браузере.
Пароль хранится в БД в виде хеша (стандартный механизм laravel), ключевая фраза хранится в localstorage 
На заключительном этапе приложение делается PWA

## Стек

- **Бэкенд** — Laravel 12 (PHP 8.2), JSON API
- **Фронтенд** — Next.js 16, статический экспорт (SPA)
- **БД** — MySQL 8

## Быстрый старт

Нужен только Docker — PHP, Composer и Node запускаются в контейнерах.

```bash
cp .env.example .env
make setup     # ключ приложения, миграции
make dev       # http://localhost:3000
```

Проверка раскладки, в которой приложение поедет на хостинг:

```bash
make prodlike  # http://localhost:8081
```

`make help` — полный список команд.
